# C Lab - Pointers, Change and Date/Time

A C lab practicing pointers, structures and basic date/time processing.

## Exercises
- `makeChange` splits a cents amount into quarters, dimes and nickels
- Parse a date and print date/time values
- Use pointer parameters to return multiple results

## Files
`lab6.c`, `lab6.h`, `lab6main.c` form the main program. The `lab6practice.*` files contain separate practice work.

## Compile and run
```bash
gcc -Wall -Wextra lab6.c lab6main.c -o lab6
./lab6
```

Enter cents and a date in the requested `dd/mm/yyyy` format. Test zero, small values, and date edge cases before relying on the output. Compile practice files separately.
